# 国・都道府県から市区町村への資金データの棚卸し

調査日: 2026-10-08
対象: 国(各府省)と都道府県から市区町村へ流れる予算・資金について、自治体単位・年度単位で取得できる公開データ。栃木県(都道府県コード 09)の市町、とくに那須烏山市(092151)と那珂川町(094111)が載っているかを実ファイルで確かめた。

## 調査の方法と凡例

- 各データについて、ページを開き、可能なものは実ファイル(CSV・Excel・PDF)を取得して列構成と市町村名の有無を確かめた。取得したファイルは調査用の一時領域に置き、プロジェクトの `data/` には保存していない。
- 総務省・e-Stat・消防庁・国交省の一部は本文書の作成者が直接確認した。国交省、その他の府省、横断 DB、栃木県・県内市町は調査担当を分けて確認し、その報告を転記した。
- 同一ホストへのアクセスは約 1 秒以上の間隔を空けた。User-Agent は `findnews-research/0.1 (inventory survey)` など。
- 「確認状況」の凡例
  - **確認済**: ページまたは実ファイルを開き、内容(列・金額・市町村名)を確かめた。「確認済(該当なし)」「確認済(存在しない)」は、探した場所を開いて該当がないことを確かめたもの。
  - **一部確認**: 一覧ページやリンクの存在は確かめたが、ファイル本体または一部の項目を開いていない。
  - **未確認**: 開けなかった、または見つからなかった。
- 「本プロジェクト取得済」は README.md(2026-10-08 時点)の「取得・パースの状況」による。
- 金額の単位は資料ごとに異なる(円・千円・百万円・億円)。表中の数値は資料の単位のまま記す。
- 「FY」は年度(4 月〜翌 3 月)。令和 6 年度 = FY2024。

### アクセス上の注意(調査中に起きたこと)

- **odm.bodik.jp**: 栃木県担当の調査で、robots.txt を読む前に CKAN API(`/api/3/action/package_search`)へ約 1.2 秒間隔で 5 回アクセスした。robots.txt は `/api/` を禁止し Crawl-Delay 10 秒を指定している。気づいた後は API を使っていない。今後この API は使わない。
- **meti.go.jp 系・mod.go.jp**: WebFetch と簡易 UA の curl が 403 を返したため、調査担当が macOS 標準の HTTP 機能で取得した(ブラウザを装う UA 偽装はしていないと報告)。meti 系の robots.txt は 403 で内容を確認できていない。mod.go.jp の robots.txt は対象ページを禁止していない。403 がサーバ側のアクセス拒否である可能性があるため、取得の自動化前に利用条件の確認が要る。

#### 結合のキー

- 団体コード(6 桁)。A1 の CSV の団体コードは FY2024 分が 6 桁(`094111`)、FY2010 分は先頭の 0 がない 5 桁(`11002` = 札幌市)で、年度によって形式が違う。
- 地方公共団体の法人番号には団体コードが含まれる(那珂川町 2000020094111、那須烏山市 7000020092151)。国交省・農水省・環境省の交付決定 Excel、RS システム、gBizINFO に法人番号がある。内閣府の CSV は法人番号が指数表記になっている。
- 福岡県那珂川市と栃木県那珂川町は名称が近いため、名称での照合では取り違える。

#### 重複計上と金額の段階の違い(資料で確認した事実)

- **配分額・交付決定額・決算額は別の数字。**
  - 配分額(B2 など)は計画単位・箇所単位で、国費の場合と事業費の場合がある。
  - 交付決定額(B1 など)は交付先単位・円単位・日付付きで、変更による減額が負の行として載る(那珂川町 防安交 2026-01-26 −719,000 円など)。計画名・箇所名はない。
  - 決算額(A1)は年度の歳入合計。
- **補正予算。**
  - 配分は当初と補正が別の公表(B2・B3・B29)。B3 の補正には「想定国費(通常)」と「想定国費(実施中期)」の区分がある。
  - 内閣府の第 2 世代交付金は R6 補正と R7 当初が同じ回で決定されている(B20)。
  - 交付決定のファイルでは、補正予算・繰越予算による交付が同じファイルの別行になる(B41)。
- **繰越。**
  - 国交省の社総交の交付決定ファイルには、予算年度別(R7 予算分/R6 予算の繰越分 等)の列があるシートがある(B1)。
  - 財務省決算 CSV では、目「社会資本整備総合交付金」FY2024 の翌年度繰越が 2,152 億円(E5)。
  - 市町村の決算書には繰越明許分が別行で出る(D1・D5)。A1 の 04 表には「繰越事業費等充当財源繰越額」の列がある。
  - このため、ある年度の交付決定額と同じ年度の決算額は対応しない場合がある。
- **国→県→市町村の経路。**
  - 国の補助が県を経由する場合、市町村の決算では国庫支出金ではなく都道府県支出金の「国庫財源を伴うもの」に計上される(A1 の 04 表の区分)。
  - RS システムの支出先には国→都道府県→市町村の間接支出が含まれる(E2)。
  - 内閣府地方創生系・農山漁村地域整備交付金の交付決定公表では、交付先が都道府県になっていて市町村の行が出ない(B27・B30)。
- **共同・広域。**
  - 社総交・防安交の共同計画は、策定主体を列挙するだけで市町村別の内訳がない(B2)。
  - 第 2 世代交付金の広域連携事業は、参加団体ごとに重複計上される(B20 の注記)。
  - 循環交付金の事業主体には一部事務組合が入る(B38)。A1 の CSV にも一部事務組合が別団体として入っている。
- **会計の範囲。** A1 は普通会計。上下水道等の公営企業会計(A19)に入る国庫補助金は、普通会計の国庫支出金に含まれない場合がある(A19 の列は未確認)。
- **名称の違い。** 那珂川町の決算書では、社総交が「地方道路交付金事業費」77,600,000 円として計上されている(D5)。同町の A1(FY2024)では、21 表の道路の補助事業費に充てた国庫支出金が 77,600 千円、04 表の「社会資本整備総合交付金」列が 64,526 千円。両者の関係は今回確かめていない。
- **重複記載。** 国交省の事業実施箇所 PDF の街路事業には「道路局との重複記載箇所あり」と注記がある(B2)。
